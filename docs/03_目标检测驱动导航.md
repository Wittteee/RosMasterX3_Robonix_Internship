# 拓展课题：目标检测驱动导航

课题目标：视觉识别目标后，**自动生成短距导航点**，并走 Robonix 风格安全流程  
（预览 → 令牌 → 人工确认 → 单次 `move_base` goal；**禁止**上层发 `/cmd_vel`）。

参考：

- [robonix](https://github.com/syswonder/robonix)
- [robonix-rosmaster-x3-safe-move](https://github.com/luoyg0831-a11y/robonix-rosmaster-x3-safe-move)
- [packages.robonix.ai/robots](https://packages.robonix.ai/robots/)（`robonix.robot.yahboom.rosmaster_x3`）

---

## 可做的简单功能（由易到难）

| # | 功能 | 说明 | 本仓状态 |
|---|---|---|---|
| A | Mock 检测 → 候选点 → 安全干跑 | 不连车，验收映射与令牌 | **已实现** `scripts/run_detect_nav.py --mock` |
| B | 检测结果注入 → 实车短距闭环 | 用 CLI 注入 bbox，接现有 `MissionRunner` | **已实现**（需车上导航栈 + rosbridge） |
| C | 订阅 YOLO/颜色话题再导航 | 接 `/darknet_ros/bounding_boxes` 或自研检测节点 | 待接车上视觉包 |
| D | 多目标选最近/指定标签 | 多框排序后只走一个候选 | 可扩展 |
| E | 检测丢失则 cancel | 执行中目标消失触发 `PREEMPTED` | 可扩展 |
| F | 视觉 + 激光门控 | 候选点再过 costmap/`make_plan` | 对齐 safe_move 参考包 |

建议验收路径：**先 A（本机）→ 再 B（实车）→ 再 C（真检测）**。

---

## 本机快速试跑

```powershell
conda activate D:\RosMasterX3_Robonix_Internship\conda_env
python scripts\run_detect_nav.py --mock
python scripts\run_detect_nav.py --mock --confirm
```

映射规则（简化）：

- 水平偏移 `offset_x` → 车头前方偏航（默认 ±30°）
- 目标越大 → 前进距离越短（已靠近少走）
- 距离限制在 `[min_approach_m, candidate_distance_m]`（默认约 0.20–0.80 m）

## 实车注意

1. 扩展板串口需出现 `/dev/myserial`（CH340），否则 `driver_node` / APP 起不来  
2. 启动 bringup + 导航栈 + `rosbridge`（9090）  
3. 本机：`ssh -L 9090:127.0.0.1:9090 jetson@IP`  
4. 真发目标才加：`--confirm --dispatch`（危险，清场 + 急停）
