# ROSMASTER X3 × Robonix 专业实习：总体实验与主题排序

> 来源：东华大学专业实习教学材料《RosMasterX3_Robonix_安全导航》  
> 工作方式：**本机写代码 + SSH 连 Jetson**；ROS 导航栈与传感器在车上跑，不要求本机部署完整 ROS。

---

## 一、总体实验

### 一句话

上层用 **Robonix** 管「去哪里、能不能走」；中间用 **桥接通信** 连 ROS；底层用 **ROS1 导航栈** 管「怎么走、发什么速度」；小车执行运动。全程强调安全边界，**不允许上层直接发 `/cmd_vel`**。

### 系统分层

| 层 | 做什么 |
|---|---|
| Robonix（MCP / Provider） | 接收意图 → 筛候选点 → 分阶段授权 → 监控状态 / 紧急取消 |
| 桥接层（roslibpy ↔ rosbridge） | Python 业务端与 ROS1 之间安全互通（WebSocket `9090`） |
| ROS1 导航栈 | AMCL 定位 + costmap + `move_base` / DWA 规划避障 |
| ROSMASTER X3 | 激光 `/scan`、里程计、IMU、麦克纳姆底盘执行 |

### 职责边界（红线）

- **Robonix**：意图与授权管控  
- **ROS**：实时导航与运动控制  
- **Provider 只允许**：发导航目标、发取消、读状态  
- **禁止**：直接发布 `/cmd_vel` 底层速度指令  

### 核心验收主流程

1. **环境部署（车上）**：Jetson TX2 NX + Ubuntu 18.04 + ROS1 Melodic + Robonix  
   启动顺序：`roscore` → `bringup` → 导航栈 → 构建 / 启动 Provider  
2. **分层验证**：先通通信 → 再验 `/scan` `/odom` `/amcl_pose` → 最后开导航权限  
3. **安全点位导航**：预览（车不动）→ 准备（状态复核 + 一次性令牌）→ 人工确认 → 下发目标 → 全程监控  
4. **两类结果要能复现**：  
   - **短距离闭环**：到达目标，`SUCCEEDED`，稳定停车（约 0.8 m 候选点 / 约 1 m 物理距离）  
   - **安全取消**：中途触发保护，状态为 `PREEMPTED`（主动中止，不是导航失败）  

### 安全导航状态机（主实验逻辑）

```text
预览阶段 ──► 准备阶段 ──► 确认执行 ──► 目标下发 ──► 全程监控
  │            │            │            │            │
  候选点筛选    全状态复核    人工授权      PoseStamped   status 回读
  车保持静止    一次性令牌    二次校验      单次触发      可紧急取消
```

## 二、实验 / 实践主题

### A. 必修主实验（课程主体）

| 主题 | 做什么 | 验收要点 |
|---|---|---|
| 1. 环境部署与运行栈搭建 | 确认硬件/系统/ROS/Robonix 版本，按层启动节点与 Provider | 各节点能起、端口与话题可用 |
| 2. 通信连通性校验 | 经 rosbridge + roslibpy 打通双向链路 | Provider 具备约定读写权限 |
| 3. 数据有效性校验 | 检查激光、里程计、定位、TF | 频率正常、坐标系一致、无异常跳变 |
| 4. 功能安全逻辑校验 | 候选点预览时车静止；状态可回读；取消可触发 | 安全限制生效后再开放执行 |
| 5. 短距离点位导航闭环 | 人工授权后下发 `PoseStamped`，实车到点停车 | `SUCCEEDED`，定位/位移误差可记录 |
| 6. 安全取消机制验证 | 运动中触发保护性中止 | 返回 `PREEMPTED`，说明是主动保护 |

### B. 实践拓展课题

| 主题 | 核心目标 |
|---|---|
| 多点巡航任务 | 多航点序列自主巡逻 |
| 目标检测驱动导航 | 视觉识别目标后自动生成导航点 |
| 视觉–激光融合导航 | 多传感器融合筛选候选导航点 |
| 动态障碍与故障恢复 | 异常场景重规划与安全处置 |
| 语音 / 自然语言任务调度 | 把自然语言拆成可执行导航任务 |

## 三、按难易 + 就业价值排序

排序原则：先把主实验跑通 → 再按「难易 × 就业刚需」做拓展。

| 优先级 | 主题 | 难度 | 就业相关度 | 说明 |
|---|---|---|---|---|
| 1 | 环境部署 + ROS 导航栈启动 | ★☆☆ | 极高 | 环境、bringup、话题排查 |
| 2 | 通信桥接与话题联调 | ★★☆ | 极高 | 跨进程/跨语言联调 |
| 3 | 传感器与定位数据校验 | ★★☆ | 很高 | 定位漂、TF、频率异常排障 |
| 4 | 短距离点位导航闭环 | ★★★ | 很高 | 经典 `move_base` 实车验证 |
| 5 | 安全管控流程（预览/令牌/取消） | ★★★ | 很高 | 工业安全与权限差异化亮点 |
| 6 | 多点巡航 | ★★★ | 高 | 巡逻/配送场景 |
| 7 | 动态障碍与故障恢复 | ★★★★ | 很高 | 现场可靠性、异常恢复 |
| 8 | 目标检测驱动导航 | ★★★★ | 高 | 视觉 + 导航 |
| 9 | 视觉–激光融合导航 | ★★★★★ | 高 | 多传感器融合 |
| 10 | 语音/自然语言任务调度 | ★★★★ | 中高 | 演示强，依赖底层稳定 |

**实操建议：** 先完整做完 **1→5（含安全取消）**，再选 **6** 或 **7**；偏算法再冲 **8/9**；自然语言放最后。
