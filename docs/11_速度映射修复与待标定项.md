# 速度映射修复与待标定项

## 2026-10-30 软件补充修正（未连接小车）

- 保留原值速度映射：请求 `vx=0.09 m/s` 时，限幅范围内 SDK 收到 `0.09 m/s`，不再乘 `0.5`。这只是下发值，不代表车身实测速度。
- 驱动和导航现在共用 `chassis_nav_calibration.json` 的线速度、角速度上限。默认底盘上限仍是 `0.1 m/s`、`0.2 rad/s`，导航最大线速度仍是 `0.09 m/s`。导航配置超过底盘上限时拒绝生成参数；角速度参数也从配置读取。
- 驱动默认读取其脚本旁的 `chassis_nav_calibration.json`，可用 ROS 私有参数 `~calibration_profile` 指定路径。缺文件或非法配置会在创建底盘实例前报错。部署时须同时更新 `pinned_chassis_driver.py`、`nav_calibration_policy.py`、`velocity_mapping.py`、`prepare_demo_nav.py`，并把仓库 `configs/chassis_nav_calibration.json` 放到部署目录的 `scripts/` 下；不要覆盖车端已验收的实测配置。
- ROS 私有限速参数仅能降低配置上限；如果主动降低，导航配置也应相应降低。超过上限的请求会保留方向限幅，并每 2 秒至多记录一次 requested/applied 日志。`/driver_node/applied_cmd_vel` 仍表示 SDK 下发值，不是传感器实测速率。
- 标定状态仍是 `pending_physical_measurement`。没有实测数据时不扩大速度、不增加补偿倍数、不自动填入最低稳定速度或标定完成标记。
- 增加离线驱动回调测试，使用模拟 ROS/串口验证 `0.09 → 0.09`、诊断话题、限幅提示及非法速度归零。本次未部署、未启动底盘、未验证物理速度。
