# 视觉目标导航最小原型

## 可填分组表的课题

**基于 Robonix 的视觉目标识别与短距离导航任务生成**。

识别指定目标标志，读取其图像位置，结合相机标定估计目标相对方向，
从 Robonix 安全导航组件返回的候选点中推荐同方向的短距离点位。
执行前展示目标并人工确认，导航执行沿用参考组件的令牌和状态监控流程。

第一阶段用二维码标志验证流程。它是标志识别，不是日常物品的通用目标检测。
后续可将检测器替换为颜色检测或预训练目标检测模型。

## 适合拆分的小功能

| 功能 | 最小实现 | 当前状态 |
|---|---|---|
| 指定目标识别 | 只接受 `X3_TARGET_A`，忽略其他标志 | 已实现真实 OpenCV 二维码解码 |
| 图像方向估计 | 根据目标中心、相机 fx/cx 和安装偏航计算左右方向 | 已实现，实机需标定 |
| 同方向候选点推荐 | 调用 Robonix `preview_move_options`，筛选方向接近且距离满足限制的点 | 已实现适配代码，尚未接通实机 |
| 重复目标拒绝 | 同一图像出现多个同名目标时不推荐点位 | 已实现 |
| 确认后导航与结果反馈 | 复用 `prepare_selected_move` 和 `execute_prepared_navigation` | 后续实机阶段，本原型没有执行接口 |
| 目标丢失取消任务 | 连续丢失超过阈值时取消当前任务 | 后续扩展，需目标跟踪及任务关联 |

## 已验证与未验证

本原型的演示使用生成的二维码图像和明确标记的模拟导航候选。
真实 OpenCV 完成图像解码；模拟候选不代表 ROS 代价地图或路径规划通过。
没有调用目标下发、令牌准备或执行能力，也没有发布 `/cmd_vel`。

不能根据二维码在画面中的大小推算米制距离。当前只推荐朝目标方向的一个短步，
不宣称已经到达物体，也不估计物体在地图中的坐标。
如果要导航到物体前的精确停靠点，需要增加深度测距、相机到机器人坐标变换，
以及目标周围的可通行性检查。

## 本机试跑

```powershell
.\conda_env\python.exe -m pip install -r requirements-vision.txt
.\conda_env\python.exe scripts\preview_visual_target.py --demo
.\conda_env\python.exe -m unittest discover -s tests -v
```

输出：`logs/vision/target_scene.png`、`annotated.png`、`result.json`。
二维码内容为 `X3_TARGET_A`。

检测真实图片时不需要导航组件：

```powershell
.\conda_env\python.exe scripts\preview_visual_target.py --image target_photo.png
```

摄像头也可使用 `--camera 0`，或可访问的相机设备/视频流。
输入源与 OpenCV 后端是否兼容，需要根据小车实际视频接口确认。

## 与参考 Robonix 包连接

参考项目：

- https://github.com/syswonder/robonix
- https://github.com/luoyg0831-a11y/robonix-rosmaster-x3-safe-move
- https://packages.robonix.ai/robots/robonix.robot.yahboom.rosmaster_x3/

适配器采用参考仓库 `jetson/scripts/move_base_cli.py` 中相同的进程内
Provider 调用方式，导入 `rosmaster_x3_bridge.main` 和生成的
`rosmaster_x3_bridge_mcp.PreviewMoveOptions_Request`。
这要求运行环境已经安装参考包、Robonix API 及生成的绑定。
普通 Python 脚本试跑不能替代 Robonix 部署验收。

真实预览需提供 `--provider-dir`（已安装包的父目录）、`--fx`、`--cx`、
`--camera-yaw-deg`。相机内参必须对应图像分辨率，并使用校正后的图像；
安装角度需要相机基本水平且俯仰/滚转可以忽略。
未提供这些参数时仅报告识别结果。`--demo` 禁止与真实 Provider 混用。

默认推荐距离上限为 0.20 m。如果参考包只返回 0.80 m 的最远候选，本原型会报告
`no_matching_provider_option`，不会放宽距离限制。
参考仓库当前版本和目录索引版本存在差异，必须确认实机实际部署版本。
